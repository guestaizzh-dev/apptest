# Windows 教师端测试包

`pnpm desktop:build` 构建 Vue 页面及 Electron Windows x64 免安装程序，产物在 `release/归途智学教师端.exe`。免安装包可直接双击运行；不依赖 Vite、Node.js 或浏览器安装。

2026-10-06：品牌统一为“归途智学”，使用提供的红底白色 logo，品牌主色为 `#bb2829`。登录、侧栏、个人信息、课堂头部、网页标题、窗口名称与 Windows 图标同步更新。课表使用全宽日历、固定日期与时间轴、课程详情抽屉，窄窗口通过日历内部横向滚动保留课程可读性；桌面开发服务忽略 `release`，避免打包中的 DLL 文件导致文件监听崩溃。

课表姓名使用深灰，状态与选中反馈保留品牌红。页头统计合并到标签栏，日期导航和搜索合并到一行（小窗口自动换行），每小时网格为 72px。浏览器实测：1440×900 可见约 7.8 小时，1536×729 可见约 5.4 小时，1000×650 可见约 4.2 小时；40 分钟课程信息无纵向裁切，外层页面无溢出。

客户端启动仅监听本机 `127.0.0.1:18376`，内置页面通过本机代理访问正式后端 `https://xueerguitu.com/api`，使用系统信任的 HTTPS 证书验证。老师电脑只需能联网，无需安装 Node.js 或启动本地后端。桌面构建使用 `.env.desktop` 的 `/api`，主进程负责线上转发；Web 正式构建也使用线上 API。

2026-10-12 线上测试包包含最新课堂布局和页面优化：采用提供的头部背景图，两个摄像头相邻显示，移除中间课程介绍和开课计时，收窄右侧工具栏和底部操作条。使用正式环境的教师账号登录，测试库账号和排课不会自动出现在正式环境。运行 `node scripts/verify-desktop.mjs --online` 可验证真实 HTTPS 代理、健康检查和未登录拦截；这不代表音视频与手机联调已通过。

摄像头与麦克风通过 Electron 的媒体权限处理，仅向客户端本地页面开放。共享屏幕或教学窗口时，桌面端弹出选择窗口；选择取消不会停止已有音视频课堂。白板同步使用 Chromium Element Capture，直接采集当前页面的白板元素，以 15fps 为目标发送既有 ZEGO 教学流，需要点击同步授课按钮。原有 500ms 快照循环已删除。元素外的摄像头、工具栏、遮挡菜单和其他应用不进入白板教学流。

白板命名使用页面内原生 HTML dialog，兼容 Electron。主窗口启用沙箱和上下文隔离，页面不能调用 Node.js；沙箱 preload 只暴露准备/取消白板采集两个固定方法。主进程验证来源为本机课堂主页面，授权只消费一次且 5 秒过期，不开放通用 IPC。后台绘制节流关闭，保证教师切到其他应用时教学画面继续更新。

检查：`node scripts/verify-desktop.mjs` 验证静态资源、历史路由、API 转发、身份头与请求体传递、目录边界和后端不可用提示。`node scripts/verify-rtc.mjs` 验证现有音视频与白板契约。Windows 包启动成功与媒体真实联调属于不同验收事项。

直接采集检查：`node scripts/verify-board-capture.mjs` 覆盖授权来源/过期/单次消费、禁止音频、裁剪前不发布、失败和退出后的迟到结果释放；`node_modules/electron/dist/electron.exe scripts/verify-board-native.cjs --output=<结果JSON绝对路径>` 在真实 Electron 中验证隐藏窗口的元素采集、菜单排除、动态帧、尺寸跟随和轨道释放。不登录业务、不请求摄像头麦克风、不进入 ZEGO 房间。原生采集检查不能替代 PC 至手机的真实课堂延迟测量。

交付文件启动检查：单文件测试包启动后创建“学而规途 · 教师端”窗口；本机代理访问后端 actuator/health 返回 UP，登录路由 HTTP 200。开发入口的启动日志确认媒体处理器、窗口创建及页面加载完成。摄像头、麦克风、窗口共享与手机白板仍需在桌面客户端内再次实房联调，不沿用浏览器版结果宣称桌面版通过。
